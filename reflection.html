MSc Artificial Intelligence

Reflection

This page reflects on my learning across the programme so far, using Rolfe et al.'s (2001) What? So what? Now what? model. Detailed reflections for each unit are on the module pages.

What?

Module 1 – Launch into Computing introduced the foundations of computing, including logic, algorithms, software engineering, data, cyber security and IT management. It connected these topics to real organisational scenarios.

Module 2 – Understanding Artificial Intelligence moved from the principles and ethics of AI to the full development lifecycle: data preparation, feature engineering, supervised and unsupervised learning, and model evaluation, using tools such as Jupyter Notebook, Scikit-learn and PyTorch.

Module 3 – Numerical Analysis built the statistical foundations behind data science and AI. I worked in R throughout, from descriptive statistics and probability to hypothesis testing, regression and Bayesian analysis, and finished with a full statistical analysis of the Pima diabetes dataset.

So what?

The biggest change in my thinking came in Module 3. I learned that a statistical result is only useful when it is interpreted carefully. A small p-value does not show how important a difference is (Greenland et al., 2016), a model can fit well and still miss many of the cases that matter, and adjusting for the wrong variable can hide a real effect. I also learned that code can run without errors and still give an incomplete answer, so every result needs to be checked.

These lessons link the modules together. Module 2 showed me how AI systems are built and evaluated, and Module 3 gave me the tools to question their results. As a network engineer, I can see the same ideas in my own work, for example when a monitoring threshold has to balance false alarms against missed faults.

Now what?

In the next modules I will report effect sizes and confidence intervals alongside p-values, use a checked R template that tests assumptions before any analysis, and take a more active part in seminars and discussions. I also plan to apply statistical thinking to network performance monitoring at work. The full action plan is on the Professional Skills page.

Reference

Greenland, S., Senn, S.J., Rothman, K.J., Carlin, J.B., Poole, C., Goodman, S.N. and Altman, D.G. (2016) 'Statistical tests, P values, confidence intervals, and power: a guide to misinterpretations', European Journal of Epidemiology, 31(4), pp. 337–350.

Rolfe, G., Freshwater, D. and Jasper, M. (2001) Critical reflection in nursing and the helping professions: a user's guide. Basingstoke: Palgrave Macmillan.
